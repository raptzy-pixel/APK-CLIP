# RAPIUZY AI Clipper — Web

Static web version of the RAPIUZY AI Clipper UI, prepared for Vercel.

## Deploy
Import this folder/repository into Vercel. No build command is required; `index.html` is served as a static site.

The current web build supports video selection, browser preview, ratio/subtitle/backsound UI, and the clip setup screen. Actual AI clipping/export requires a backend API.
